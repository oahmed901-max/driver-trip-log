# سجل حركة السواقين — Driver Trip Log

نظام لتسجيل ومتابعة حركة سواقين الشركة، مبني بـ Streamlit وSupabase.

## بنية المشروع
```
driver-trip-log/
├── app.py                          # نقطة الدخول - يوجّه لشاشة السواق أو المشرف
├── db.py                           # كل الاتصال بقاعدة البيانات
├── driver_view.py                  # شاشة السواق (بدء / إنهاء رحلة)
├── supervisor_view.py              # لوحة المشرف
├── qr_utils.py                     # توليد كود QR
├── requirements.txt
├── .gitignore
└── .streamlit/
    └── secrets.toml.example        # مثال فقط - الملف الحقيقي (secrets.toml) ما يترفعش أبداً
```

## خطوات النشر (Streamlit Community Cloud)

1. تأكد إن ملف `schema.sql` اتشغّل بالفعل في Supabase (SQL Editor) وإن الجداول ظاهرة في Table Editor.
2. ارفع كل ملفات المشروع دي على الـ GitHub repo بتاعك (ما عدا `.streamlit/secrets.toml` الحقيقي - ده ميترفعش خالص).
3. روح على share.streamlit.io وسجّل دخول بحساب GitHub.
4. اضغط "New app"، اختار الـ repo، وحدد `app.py` كملف رئيسي.
5. قبل ما تشغّل التطبيق، روح لـ "Advanced settings" → "Secrets" والصق فيها:
   ```toml
   SUPABASE_URL = "..."
   SUPABASE_KEY = "..."
   SUPERVISOR_PASSWORD = "..."
   APP_BASE_URL = "https://your-app-name.streamlit.app/"
   ```
   (القيم دي هتلاقيها في Supabase → Project Settings → API، و APP_BASE_URL هو الرابط اللي هيديهولك Streamlit بعد أول نشر)
6. اضغط Deploy.

## أول استخدام
1. افتح رابط التطبيق (من غير أي إضافة في الآخر) → هيوديك لصفحة تسجيل دخول المشرف.
2. سجّل دخول بكلمة المرور اللي حطيتها في Secrets.
3. تبويب "العربيات" → ضيف عربيات الشركة وقراءة العداد الحالية لكل واحدة.
4. تبويب "السواقين" → ضيف كل سواق، وهيتولّدله رابط وكود QR تلقائي.
5. ابعت لكل سواق رابطه الخاص (أو كود الـQR) عشان يستخدمه من موبايله.

## ملاحظات أمان
- الرابط/QR الخاص بالسواق وسيلة تعريف سريعة، مش نظام حماية قوي — أي حد معاه الرابط يقدر يسجل باسم السواق ده. لو محتاج حماية أقوى لاحقاً، الخطوة الجاية هي نظام تسجيل دخول حقيقي للسواقين (username/password أو OTP).
- كلمة مرور المشرف حالياً بسيطة (كلمة واحدة مشتركة). لو أكتر من مشرف هيستخدموا اللوحة، الأفضل لاحقاً الانتقال لـ Supabase Auth بحسابات منفصلة لكل مشرف.
